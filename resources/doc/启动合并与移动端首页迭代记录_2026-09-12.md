## 二、迭代 A：启动 IPC 合并

**背景**：App.vue 启动并行触发 ~7 个 IPC（play_queue / counts / playlists / source_list / albums / album_count / artists）。第六、七轮 async 化 + 封面后台化后，剩余开销主要是 WebView 端的请求数本身。

**改动**：

- 新增命令 `library_get_startup_bundle`（`#[tauri::command(async)]`，模型 `models.rs::StartupBundle`）：一次返回 counts（复用 library_get_counts 的 SQL）、playlists、专辑网格第一页 30 条（含内联缩略图，与 `get_albums_paginated(30,0,None)` 完全同形）+ album_total、艺人第一页 50 条 + artist_total、持久化播放队列。
- **30 / 50 两个分页常数与前端 `albumsPageSize` / `artistsLimit` 对齐**（代码注释已互指），前端据此续接无限滚动。
- `source_list` 保持独立——凭据解析（钥匙串 / `##kr:` 引用）逻辑在 scanner 模块，为省一个 IPC 把它拉进 library 命令得不偿失。**启动 IPC：7 → 2。**
- 前端：`stores/player.ts` 新增 `fetchStartupBundle()`（应用 counts/playlists/albums/artists/queue 并校正 `albumsOffset` / `hasMoreAlbums` / `artistsOffset` / `hasMoreArtists` 分页游标）；`restoreSession(bundle?)` 改为纯本地恢复（播放模式/音量/进度走 localStorage，队列已随包就位，bundle 缺失时回退旧路径兜底）；App.vue 启动流程改为 bundle → restoreSession → fetchSources。
- 启动失败兜底：bundle 拉取失败返回 null，restoreSession 走旧的逐个 IPC 路径，不会白屏。

## 三、迭代 B：移动端首页

**改动**：

- `stores/ui.ts`：`MobileTab` 增加 `'home'`，`activeMobileTab` 默认改 `'home'`（与桌面 `activeLibraryTab='首页'` 对齐）。
- `MobileTabBar.vue`：新增「首页」tab（Home 图标，置于首位）。
- `MobileLayout.vue` 的 tab 同步 watch：`case 'home'` → `activeLibraryTab = '首页'`；从首页切回「曲库」时，既有 `isLibraryTab` 守卫自动纠正为「全部歌曲」。
- `MobileHeader.vue`：标题 case、`showMeta` / `showBackButton` 对首页隐藏（首页是根页）。
- `MobileContentView.vue`：`isHomeView` 分支渲染 `HomeView`（置于分支链首位），`loadForCurrentTab()` 对 `'首页'` 直接 return。
- `HomeView.vue` 响应式（桌面/移动共用一份组件，不复制）：
  - 容器 `px-4 md:px-8 py-4 md:py-6`；标题 `text-[24px] md:text-[32px]`（24 = LDL `--text-mobile-page-title`）；
  - 统计卡 `grid-cols-2 md:grid-cols-4`；排行榜 `grid-cols-1 md:grid-cols-2`。
- **返回键**：`useMobileBack` 的快照栈存的是 mobileTab/libraryTab 字符串，`'home'` 天然兼容，无额外改动。

**注意点**：MobileLayout 的 immediate watch 会在启动时把 `activeLibraryTab` 设为 `'首页'`，此时 MobileContentView 的 `loadForCurrentTab` 不会发任何 IPC——首页自管 + 启动包已备齐网格数据。

## 四、迭代 C：批量操作补齐

- **AlbumDetail.vue**：多选入口加在「播放全部 / 随机播放」旁（与 PlaylistDetail 同款）；切换专辑（`watch(albumId)`）自动退出多选；行单击切换选择、序号列换复选框、心形与艺术家链接改切换选择、双击播放禁用；底部 BatchActionBar。至此 7 个列表视图全部支持批量。
- **FolderView.vue**：表头 ListChecks 图标入口；切换文件夹（`watch(selectedTreePath)`）自动退出；行为同上；BatchActionBar 置于右侧文件列表面板底部。
- **导航统一**：AlbumDetail / FolderView 的旧内联跳转（`activeLibraryTab = '艺术家'; activeArtistId = ...`）统一替换为 `playerStore.navigateToArtist()`（同 tick 改 id + tab，历史只记一条）。

## 五、迭代 D：LDL 暖色中性阶梯

- `style.css` `@theme` 注册 `warm-300..800`（取值 = Tailwind stone 阶梯，暖灰），LDL「绝不冷灰」从约定变成 token。
- 替换 8 处冷灰占位渐变：`player.ts::getDeterministicColor` 色板 1 处、ArtistGrid / ArtistDetail 兜底 3 处、MobileArtistDetail / MobileSearch / MobileContentView 占位 4 处（`gray-*` → `warm-*`）。
- `lib.rs` 移除 `register_uri_scheme_protocol("lumo")` 入口的 `[PERF]` artwork 计数诊断日志（定位期遗留）。

## 七、经验与约定

1. **bundle 里的分页常数必须与前端对齐**（30/50），改任一侧要同步另一侧；注释已双向互指。
2. **`restoreSession` 保留无 bundle 兜底路径**——启动包失败不阻塞播放会话恢复。
3. **占位渐变一律用 `warm-*`**，不再引入 `gray-*`（LDL token 已注册，直接可用）。
4. 移动端 tab 新增时需过一遍四处：`MobileTab` 类型、TabBar 列表、Layout 同步 watch、MobileHeader 标题/返回逻辑。

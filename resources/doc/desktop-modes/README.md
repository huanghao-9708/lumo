## 1. 本轮目标

把桌面体验拆成两个独立维度：

- **体验模式**：正常 / 极简。决定视觉增强、图片加载与可选任务策略。
- **窗口形态**：完整窗口 / 迷你播放栏。决定当前挂载的界面与窗口几何。

用户可在日夜主题按钮旁切换体验模式，也可进入迷你播放栏，返回时保留原体验模式、播放状态与浏览上下文。极简和迷你必须实际减少界面资源与可选任务，不能只隐藏 DOM 或缩小窗口。

功能目标是低开销、顺畅、可恢复；Windows 整组进程播放稳态约 100 MiB 是探索目标，不是本轮预先保证的交付结果。验收以同场景对照数据为准。

## 3. 已确认范围与实施假设

| 类型 | 内容 |
|---|---|
| 用户已确认 | 两个独立维度；正常/极简入口靠近日夜主题；迷你栏只保留信息与必要操作；优先降低内存并保证流畅 |
| 本轮实施方案 | Windows 首先验证；复用单个 Tauri 窗口和 Rust 播放核心；完整/迷你通过互斥挂载切换 |
| 初始设计值，可依验收调整 | 迷你默认 560×96 逻辑像素、最小 480×96；按钮点击区域至少 32×32；文本不持续跑马灯 |
| 保留的核心能力 | 音质、播放/暂停/切歌/Seek、队列语义、本地/WebDAV、搜索、歌单、收藏、备份恢复 |
| 不纳入本轮 | 原生 UI 重写、第二个常驻 WebView、系统托盘、额外热键体系、AI 扩展、移动端极简/迷你产品入口 |

Android 保持原体验；共享代码改动必须回归。macOS/Linux 仅按当前平台承诺做构建和可执行的回归，不因本轮升级支持等级。

## 4. 代码核验基线

以下来自本次读取的代码，区别于旧计划中已过时的实现描述。

| 当前入口 | 观察 | 本轮必须处理 |
|---|---|---|
| `src/App.vue` | 根组件持有启动和全局事件；桌面五区布局常驻；沉浸页条件挂载 | 播放会话保持常驻，完整浏览界面与迷你栏互斥挂载 |
| `src/components/layout/TopBar.vue` | 日夜主题、信息面板、设置和窗口控制 | 新增体验菜单、迷你入口，不挤压搜索和窗口控制 |
| `src/composables/usePlatform.ts` | Android 或视口宽度 <768 判定为移动布局 | 桌面迷你形态必须优先于宽度断点，不能落入 MobileLayout |
| `src/composables/useWindowPersistence.ts` | 完整窗口最小 1024×640；resize/move/scale 事件重新约束；400ms 保存防抖 | 按形态保存和约束；清理旧回调，防止迷你被拉大或覆盖完整尺寸 |
| `src-tauri/tauri.conf.json` | 一个主窗口，默认 1200×720、最小 1024×640 | 迷你运行时约束；冷启动在展示前应用正确形态 |
| `src-tauri/capabilities/default.json` | 已允许 set-size、set-size-constraints、center 等；置顶等权限需核验 | 按实际调用补最小权限，不能为迷你开放全部窗口权限 |
| `src/composables/useArtworkSrc.ts` | 当前走协议 URL，无 JS fetch/预取队列；旧统计字段恒为 0 | 统一需求门禁；协议请求和解码不能用这些 0 值证明停止 |
| `src/components/layout/NowPlayingImmersive.vue` | 原尺寸封面、缩略图取色、模糊光晕和动画 | 极简用文字播放页；迷你不挂载；取消相关异步任务 |
| `src-tauri/src/lib.rs` | 启动时后台缩略图回填；启动 Rust 队列 watcher | 启动前读策略；可选图片任务可暂停，播放 watcher 保持 |
| `src/stores/player.ts` | 播放/浏览混合；扫描完成自动刷新歌曲/专辑/艺人；MediaSession 携带封面 | 按需求处理刷新、通知图片和轻量会话；释放浏览数据不破坏队列 |
| `library_get_startup_bundle` | 聚合启动曲库、歌单、专辑/艺人、队列等 | 迷你冷启动用会话摘要；完整浏览启动按需要加载 |
| `src-tauri/src/services/queue.rs` | Rust 队列已存在；状态 DTO 可含整条队列 | 新增轻量会话读取；避免迷你复制整个队列，保留旧接口兼容 |
| `scripts/measure-memory.ps1` | 按产品进程组采样 PWS、Private Bytes、CPU、句柄等 | 复用脚本，增加模式/形态标注与窗口转换时序 |

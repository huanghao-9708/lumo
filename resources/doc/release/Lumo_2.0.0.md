# Lumo 2.0.0 发布说明

> Android 安装包尚未经真机验证，仅供预览测试。macOS 与 Linux 安装包同属技术预览，尚无完整运行验证。Windows 安装包尚未进行 Authenticode 签名。

## 桌面端变化

- 默认窗口调整为 1200 × 720，最小窗口为 1024 × 640；窗口大小会记忆，并在显示器工作区或缩放比例变化后重新限幅。
- 侧栏移除逐项计数，保留页面中的概览统计。
- 曲库、收藏、最近播放、歌单、专辑、艺人、文件夹和搜索结果使用一致的歌曲表头、行样式与列设置。可切换标准/详细视图，并选择年份、流派、文件大小等列；音频信息集中显示格式、码率或位深与采样率。
- 扫描会提取年份、流派和位深。旧曲库在各个本地或 WebDAV 来源完成首次重新扫描后逐步补齐；首次补扫可能比日常增量扫描耗时更长。
- 修复窄窗口的列宽预算、播放队列与列表对齐问题，以及歌曲行的歌单操作入口。

## 升级与数据

- 推荐从 1.8.6 或 1.9.0-beta.1 升级。升级前请备份曲库数据库；本次数据库由 V12 升至 V13，增加流派关联索引及每个来源的元数据补扫标记。
- V13 不删除旧字段；新版本完成扫描后，旧客户端不会读取新增加的补扫标记，但回退到旧版本前仍建议保留备份。

## 验证范围

- 前端类型检查、69 项单元测试、生产构建、Rust 格式与严格静态检查、109 项 Rust 测试均通过。
- Windows x64 NSIS 安装包已在本地成功构建；依赖审计没有高危漏洞。
- 窗口尺寸、显示器切换、安装升级与回退、Android 真机及 macOS/Linux 运行仍需按[验收检查表](../桌面端重构验收检查表_2026-09-29.md)进行人工验证。

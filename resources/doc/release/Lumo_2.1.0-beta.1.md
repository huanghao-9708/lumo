# Lumo 2.1.0-beta.1 发布说明

> 测试版：桌面新模式完整验收尚未完成。Android APK 未经真机矩阵验证，仅供预览；macOS/Linux 为技术预览；Windows 安装包未作 Authenticode 签名。

本次新增桌面极简体验与迷你播放栏，并修复歌曲列表多选等问题。沿用 2.0.1 的曲库数据库结构，无新增曲库迁移；升级前建议保留现有备份。

## 变化

- 桌面正常/极简体验与完整/迷你窗口独立切换，保存各自窗口偏好；播放会话跨界面保持，迷你冷启动使用轻量会话。
- 极简界面显示文字歌曲、专辑和艺术家列表；迷你窗口卸载完整浏览界面，停止可选视觉任务并释放浏览缓存。
- 修复完整窗口体验菜单被内容遮挡、极简专辑/艺术家无法加载后续页、艺术家详情残留全库页头和专辑封面的问题。
- 首页 AI 电台入口遵循设置中的启用状态。
- 移除歌曲列表无效的视图切换按钮；九种歌曲列表统一多选入口，提供选中高亮、数量、全选/取消全选、批量收藏和加入歌单。长列表滚动时批量工具栏保持可见。
- 修复浏览/可播性迟到响应、播放会话位置保存、空队列残留进度，以及迷你模式系统媒体文字和封面需求的问题。

## 验证与边界

- 本轮前端 148 项回归、类型检查与生产构建通过；Windows 开发窗口验证上述分页、详情、菜单、AI 入口与多选显示路径。
- 桌面模式 Windows 局部窗口/播放恢复已有实机证据；历史实验版 MM 三首循环曾连续播放 30 分钟。该记录不等于本发布二进制的性能测量，不承诺固定内存上限。
- 多显示器/DPI、真实 WebDAV、系统媒体实际呈现、四组合完整长测与配对性能验证仍有缺口，详见 [M4 执行记录](../desktop-modes/M4_执行记录.md)。Android 不新增极简/迷你产品入口。
- Beta 安装包启用桌面新入口；Stable 构建开关仍默认关闭。Windows 测试版提供 NSIS 安装包，MSI 不支持该 Beta 版本格式。

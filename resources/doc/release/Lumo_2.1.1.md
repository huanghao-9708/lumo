# Lumo 2.1.1 发布说明

> 正式版本（Windows x64）。此版本未作 Authenticode 签名；Android 真机验收尚未完成；macOS/Linux 为技术预览，本次 Stable 仅提供 Windows 安装包。桌面极简/迷你模式入口已开放，相关长时间性能与完整矩阵验收仍在进行。升级前请保留已有数据库备份。

最低升级版本：2.0.1。此版本不新增数据库迁移。

## 修正

- 恢复正式版的桌面极简模式和缩小播放栏入口。2.1.0 Stable 的发布配置意外关闭了前后端共用的模式开关；2.1.1 Stable 与 Beta 一样启用该开关。
- 其他播放、曲库和偏好设置行为保持 2.1.0。

## 验证范围

- 前端类型检查、单元测试、生产构建、版本一致性与联网行为登记检查通过。
- Rust 格式检查、Clippy 严格检查与单元测试通过。
- 桌面模式的局部窗口切换、极简艺术家/专辑分页与深页恢复已有 Windows 实机记录；2.1.1 发布包仍需用户继续完成长时间配对性能测量。
- Android 真机、macOS/Linux 运行验证、多 DPI/多显示器及 M4/M5 完整矩阵仍未完成。模式入口开放不代表这些验收项已通过。

- **日期**：2026-10-01

# Lumo 2.1.0 发布说明

> 正式版本。Stable 安装包仅面向 Windows x64，且未作 Authenticode 签名。Android 尚未完成真机验收；macOS/Linux 属于技术预览，此版本不提供这些平台的安装包。桌面极简/迷你模式仍是 Experimental：Stable 构建默认隐藏入口。升级前请保留已有数据库备份。

最低升级版本：2.0.1。此版本不新增数据库迁移。

## 变化

- 统一桌面歌曲列表的多选入口，提供选中高亮、选择数量、全选/取消全选，以及批量收藏和加入歌单。
- 移除没有实际效果的歌曲列表视图切换按钮。
- 首页 AI 电台入口遵循启用设置；关闭时隐藏。
- 修复艺术家详情页头、专辑封面，以及极简专辑/艺术家列表分页等体验问题。
- 修复浏览恢复时的列表深页位置、目录和智能歌单状态，以及播放会话恢复中的队列错位问题。
- 改善系统窗口还原后的最大化状态恢复。

## 验证范围

- Windows 自动化回归：179 项测试通过；类型检查、生产构建及版本/联网登记通过。
- Windows 11 本机的完整/迷你窗口往返、极简专辑/艺术家深页恢复和完整会话冷启动经过实机复验。
- 最终构建完成约 5 分钟迷你播放采样，整组 PWS 中位数 101.50 MiB、峰值 104.40 MiB。这是短时单轮数据，不代表长期或配对性能结论。
- M4/M5 长时间配对性能、WebDAV、音频听感、多 DPI/多显示器、Android 真机和 macOS/Linux 运行验证仍未完成。桌面显示模式仍保持 Experimental，未纳入 Stable 默认入口。

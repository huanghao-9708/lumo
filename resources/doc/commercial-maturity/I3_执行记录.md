## 2. 本轮实测证据（本地跑过，非"应当能过"）

```text
cargo fmt --check                                   -> exit 0
cargo clippy --offline --all-targets -- -D warnings -> 零告警
cargo test --offline                                -> 33 passed / 0 failed / 1 ignored(基准)
cargo test --release --test perf_baseline -- --ignored --nocapture -> 通过，输出 §3 表
node scripts/check-network-registry.mjs             -> exit 0（退避改动未新增任何外联端点字面量）
npm run typecheck                                   -> vue-tsc 零错误
npm run test:unit                                   -> vitest 15 passed / 0 failed（G-08 前端四处行为）
```

负向验证（测试必须真有牙齿）：

- `exp_backoff(0)` 的第一版实现返回 `base` 而非 `ZERO`，被 `backoff_doubles_and_caps` **当场判失败**
  （`left: 1s, right: 0ns`）→ 修函数而不是改断言；
- `backoff_never_collapses_to_zero_on_extreme_counts` 专门钉住"移位回绕成 0 延迟"这一类退避失效；
- 上一轮（`52a8cf2`）的 `truncated_cache_is_rejected_and_removed` 与
  `download_guard_is_exclusive_and_releases_on_drop` 同理：先写坏行为断言，再实现；
- 前端测试做了一次**变异验证**：把 G-08 的四处修复逐项改回修复前的写法
  （删 `last_error` 映射、`scan-complete` 写死"刚刚扫描"、桌面文案退回二分枝、移动错误行 `v-if="false"`），
  对应 5 例分别转红；还原后 15 例复绿。断言不是恒真。

数据库/查询层基线（Windows 10.0.26200 x64 / rustc 1.93.1 / release，完整表见 `PERFORMANCE_BASELINE.md`）：

| 指标 | 1k | 10k | 30k |
|---|---:|---:|---:|
| 首屏列表 200 条 | 4.2 ms | 40.3 ms | 127.6 ms |
| 同排序裸取 200 id（归因对照） | 0.2 ms | 2.1 ms | **6.4 ms** |
| 关键词 `LIKE` | 2.0 ms | 18.4 ms | 56.7 ms |
| 扫描前全量缓存加载 | 0.4 ms | 3.7 ms | 12.2 ms |

→ 暴露真实缺陷：首屏列表是 O(N)，约 95% 成本来自 SELECT 列表相关子查询在全表求值。已登记 B-20。

### DATA-003 WebDAV 兼容实验室

| 执行点 | 状态 |
|---|---|
| Range 返回 206 时严格验证 Content-Range | ✅（偏移不符即报错停止解码） |

| 401/403 明确文案 | ✅（且不清空曲库） |

| TLS 错误不建议关闭证书校验 | ✅ 全仓无 `danger_accept_invalid_certs`；⚠️ 但也没有"证书不受信"专门文案 |

| 下载临时文件 + 校验成功后原子改名 | ✅ 后缀为 `.tmp`（计划写 `.part`，语义等价，不做无意义改名） |

### DATA-004 缓存与磁盘异常

✅：不完整缓存不得作为可播完整文件（三处同口径）；DB 与磁盘不一致可自愈（坏缓存即删即重下）；
淘汰不删写入中的 `.tmp`、命中即 touch 使正在播放的文件排在最后；用户清理缓存只删缓存目录，
不触曲库/歌单/收藏；`clear()` 不虚报释放量。

❌ / ⚠️：

- ❌ 写入前检查可用空间与 ENOSPC 专门文案（现在会失败成 `Download write failed`，不损坏数据但提示不可行动）；
- ❌ **启动时清理陈旧 `.tmp`**：崩溃遗留的临时文件既不被 prune 删除，又计入 `size_bytes()` → 新登记 G-14；
- ⚠️ 缓存只记录预期大小，无来源标记/校验和字段（`media_files.etag`、`content_hash` 存在但未参与缓存判定，L-6）；
- ❌ 只读目录、磁盘满、权限变化三类测试。

### DATA-005 可重复性能基准

✅ 生成式数据集与规模（1k/10k/30k）；✅ 基准调用生产查询；✅ 预热 + 5 次取中位/最大；
✅ 固定环境元数据入文；✅ `PERFORMANCE_BASELINE.md` 落地；✅ 公开声明改为实测区间并列出禁止声明项。

❌ 冷启动/热启动/首播/切歌/内存/安装包/局域网与弱网 WebDAV 全部未测（文件 §4 逐条列明归属）；
❌ 回退阈值未进 CI（建议 >20% 阻断，需夜间 job，本机基准单次约 12 秒）。

## 5. 本轮决策记录

1. **门禁只拦"今天就能机器判定"的项**。不做假绿的山寨测试（例如给 Vue 组件写快照测试充当"前端覆盖"），缺口写进文档比刷绿更有价值。
2. **`release.yml` 内联复制门禁而不是跨工作流复用**。GitHub 不支持 `needs` 跨 workflow；用 `workflow_run` 串联会让发布依赖另一个 workflow 的完成状态，首跑调试成本高。代价是同一次 push 上 CI 与 preflight 重复计算，接受。
3. **Rust 工具链保持浮动 stable**，不写 `rust-toolchain.toml`。理由：本机 1.93.1 与 Android 交叉编译链耦合，钉死后 gen/android 构建环境需同步改；浮动代价是新 clippy lint 可能让 PR 变红——这属于可预期且必须在某次迭代处理的技术债，用 preflight 挡住发布即可。复审点：I4 签名与更新工程。
4. **`check-network-registry.mjs` 只校验"文件是否登记"，不校验 URL 是否穷尽**。图片实际主机由服务端响应决定（网易云 CDN、mzstatic），任何逐 URL 白名单都会假装可枚举并很快失真。

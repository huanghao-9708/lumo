# Lumo 产品契约（PRODUCT_CHARTER）

> 文档状态：v1.0 待产品负责人确认（I0 / PC-003）
> 本文件取代 `VISION.md` 中关于**当前能力、联网边界与术语**的一切描述。`VISION.md` 保留为历史愿景文档，其与本契约冲突处一律以本契约为准。
> 能力状态的事实源：`FEATURE_MATRIX.md`；联网行为的唯一事实源：`NETWORK_BEHAVIOR.md`。本文件不复制二者内容，只引用。

## 1. 一句话定位

**Lumo 是给"自己攒了大量音乐文件"的人用的本地优先播放器：曲库索引在自己机器上，NAS/WebDAV 里的音乐可以直接听，装了就能用，不需要为它部署任何服务端。**

三条核心价值：

1. **数据在你手里**：曲库、歌单、收藏、播放历史存在本地 SQLite；整份应用数据是一个目录，可拷走、可备份、可删干净。
2. **不折腾就能用**：双击安装 → 指一个目录 → 出声。不需要 Docker、不需要服务端、不需要账号。
3. **默认安静**：默认零联网、零遥测、零上报。所有外联都是用户逐个开关、逐个配置的（清单见 `NETWORK_BEHAVIOR.md` §1）。

三条非目标（本契约周期内不做）：

1. 不做流媒体平台、不做在线音乐搜索与下载、不做社交。
2. 不做自建服务端，不为 Lumo 配套任何云后端。
3. 不做功能扩张换取增长，不追求功能数量对齐 Spotify / foobar2000。

## 2. 目标用户与核心问题

| 用户画像 | 核心问题 | Lumo 的解法 | 当前状态 |
|---|---|---|---|
| 有大曲库的本地音乐持有者（数千至数万首） | 文件管理器和流媒体客户端都不适合：前者没有曲库概念，后者没有你的文件 | 文件与歌曲分离建模 + SQLite 索引 + 多维浏览 | 桌面 Stable |
| NAS / WebDAV 用户 | 音乐在 NAS 上，要么先拷到本地，要么没有能直接流播的播放器 | WebDAV 远程曲库 + HTTP Range 流播 + 透明缓存 | Beta |
| 隐私敏感用户 | 想要现代体验，但不接受"听了什么"被平台收集 | 默认离线 + 逐项联网开关 + 无遥测 | Beta（存在 P1 缺陷，见 §5） |
| 需要在多设备间接续收听的人 | 换设备后歌单、收藏、历史丢失 | WebDAV 数据库快照备份恢复 | **Beta，且明确不是"同步"** |

**优先服务前两类**。第三类的隐私承诺是本产品的信任基础，因此本契约对其要求最严（§5）。

## 3. 不可妥协原则

### ① 本地优先

曲库浏览、检索、歌单、收藏、历史全部由本地 SQLite 提供，断网 100% 可用。**任何新功能不得引入"必须联网才可用"的核心路径。**

### ② 默认拒绝联网

- 新增外联能力默认关闭，且必须同时提供关闭开关与文档条目。
- 禁止应用启动、心跳、后台常驻类未授权请求。
- 每次新增出网代码必须在同一 PR 更新 `NETWORK_BEHAVIOR.md`，否则评审打回。
- **口径以代码为准**：发现文案与真实行为不符时，修正文案，不得为维护旧承诺而隐瞒既有能力。

### ③ 零遥测

不发送任何统计、崩溃上报、行为分析。当前经代码核验成立（`NETWORK_BEHAVIOR.md` §1：七类外联中无一为遥测）。此条为对外可承诺的硬契约，违反即 P0。

### ④ 非侵入

只建立索引指向用户的音乐文件，永不移动、复制、修改源文件。卸载后音乐完好。例外：用户显式发起的标签批量写入（设置元数据）属于用户主动操作，不违反本条。

### ⑤ 数据可恢复

- 任何扫描、迁移、恢复操作失败都不得让既有曲库不可用。
- 升级前必须能通过 `PERFORMANCE_BASELINE.md`/迁移测试证明历史库可安全升级；不满足则不得发布。
- 破坏性操作（整库恢复）必须有本地回退副本与前置校验。

## 4. 术语契约（强制）

| 术语 | 允许的含义 | 禁止的表达 |
|---|---|---|
| **备份恢复** | 把整份 Lumo 数据库快照上传到 WebDAV，或从快照覆盖恢复到本机 | ❌ 不得称"同步 / 多端同步 / 自动同步" |
| **远程曲库** | 直接把 WebDAV 上的音频作为曲库来源扫描并流播 | ❌ 不得暗示文件已下载到本地或被 Lumo 托管 |
| **透明缓存** | 播放远程文件时按需在本地落盘以加速后续播放 | ❌ 不得称"离线下载"（当前无用户可控的离线下载队列） |
| **AI 电台** | 用用户自备的 AI 服务商，基于本地曲库生成推荐歌单 | ❌ 不得称"推荐算法服务"或暗示 Lumo 提供模型 |

**"同步"一词保留给未来实现**：只有当具备实体级合并与冲突处理（而非整库覆盖）时，才允许重新使用"同步"表述。该边界写入本契约，任何文档与 UI 违反即视为产品承诺失真。

## 5. 联网能力的产品定位（逐条决策）

| 能力 | 定位 | 决策与理由 |
|---|---|---|
| WebDAV 远程曲库 | **核心能力（Beta）** | 产品差异点。但服务端差异未验证，未达 Stable 门槛（`FEATURE_MATRIX.md` V-01~V-04）。 |
| 在线歌词（LRCLIB） | **可选增强（Beta）** | 默认关闭。需在 I2 补请求超时、修正触发条件文案。 |
| 在线封面（网易云 + iTunes） | **可选增强（Beta，附合规风险）** | 依赖网易云非公开接口并伪装浏览器 UA（`NETWORK_BEHAVIOR.md` R-01）。**产品负责人需在 I2 决定：公开声明并保留，或改接开放数据源。**在决定前，对外文档必须如实披露网易云，不得只写 iTunes。 |
| 数据备份恢复 | **核心能力（Beta）** | 整库覆盖语义存在数据损失风险，须完成 I3 的校验/回滚测试才可称 Stable。 |
| AI 电台 | **可选增强（Beta），非核心卖点** | 决策 D-01：默认关闭、需自备 Key、移动端无 UI 入口、且存在"关闭态仍外发测试请求"缺陷（`commands/ai.rs:67-74`）。**不得用于对外宣传**，不得写入"核心功能"栏目。 |
| 更新检查 | **辅助能力（Beta）** | 仅移动端手动触发；桌面为跳转 Releases 页。需在隐私声明中如实列出 GitHub。 |

**已知 P1 隐私缺口（本契约周期必须关闭，当前尚未修复）**：

1. 两个隐私开关存 localStorage，不随备份迁移、清 WebView 即重置（`NETWORK_BEHAVIOR.md` R-07）。
2. 隐私门禁依赖前端传参，直连 IPC 可绕过（同上）。
3. AI 在关闭状态下点「测试连接」仍外发并携带 API Key（R-01/D 项）。
4. 打开设置页会自动对 WebDAV 发 PROPFIND（R-08）。

上述任一项未修复前，对外表述统一使用「**默认离线，联网行为均可逐项关闭**」，**不使用**「零联网」「绝不上传」「完全离线」这类绝对承诺。

## 6. 平台承诺范围

| 平台 | 对外承诺等级 | 说明 |
|---|---|---|
| Windows x64 | **正式支持（Stable 候选）** | 唯一有系统化验证记录的平台，Stable 发布以此为默认交付目标。 |
| Android (aarch64) | **正式支持（Beta）** | MA0–MA5 已闭环，但复核文档中 4 条 P0/P1 未确认关闭；须复核后升级。 |
| macOS | **技术预览（Technology Preview）** | CI 构建，无真实验证记录，不承诺可用性、不提供支持 SLA。 |
| Linux | **技术预览（Technology Preview）** | 仅 CI 编译，凭据存储存在弱加密回退（I2 处理），不承诺可用性。 |

**禁止**：在任何对外文案中出现"原生支持 Linux/macOS"或"全平台"字样，除非对应平台完成 `FEATURE_MATRIX.md` §5 的验证待办。

## 7. 不做什么（本期冻结清单）

商业成熟化周期（I0–I6）内，除 P0 缺陷、数据损坏、安全漏洞、构建阻断外，**不新增任何功能**。具体冻结项：

- 新音频格式、均衡器、歌词编辑器、歌词翻译、音效
- 新的 AI 模式或推荐算法改进
- 实体级多端合并同步（属未来能力，需独立立项）
- 大规模视觉重做、新主题插件
- iOS 版本
- 性能微优化（须先有 I3 基准数据）
- 应用商店上架投入（须先完成签名与政策）

未列入本清单的新需求，一律先进 `POST_STABLE_BACKLOG.md`，不插入当前迭代。变更控制规则见该文件 §3。

## 8. 对外可说 / 不可说速查

| 可以说 | 不能说 |
|---|---|
| 「本地优先，曲库数据保存在你自己的机器上」 | 「数据绝对不出本机」（存在用户开启后的外联） |
| 「默认离线，联网行为逐项可关」 | 「零联网」「无遥测」以外的绝对化表述（P1 缺口未修完前） |
| 「支持从 NAS / WebDAV 直接流播，无需先下载到本地」 | 「全平台原生支持」 |
| 「可以整库备份到 WebDAV 并在新设备恢复」 | 「多设备自动同步」「同步你的歌单」 |
| 「Windows 与 Android 可用，macOS/Linux 为技术预览」 | 「跨平台」而不加限定 |
| 以 `PERFORMANCE_BASELINE.md` 实测区间描述体积/内存/扫描规模 | 「< 10MB」「< 80MB」「20 万曲库不劣化」 |

## 9. 验收与复审

- 本契约由产品负责人确认后生效；生效前 I1 不得开始设计 Stable 范围测试。
- 复审触发：新增任何外联能力、改变任一平台承诺等级、`FEATURE_MATRIX.md` 状态升降、Stable 发布前。
- 所有偏离本契约的决定必须写入 `DECISION_LOG.md`，含日期、负责人、复审时间。

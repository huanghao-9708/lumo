# LUMO 移动端发布检查清单（Release Checklist）

> 适用版本：Lumo Android v1.x 系列发版
> 配套规划：[00_移动端总体迭代计划.md](./00_移动端总体迭代计划.md) · [MA5_打包发布与质量门禁.md](./MA5_打包发布与质量门禁.md)
> 规则：每次发布正式 APK 前，发布责任人必须逐项复核并勾选，确认 100% 达标后方可发布 Release。

---

## 1. 代码与构建门禁（Build & CI）

- [ ] **单一版本号对齐**：`src-tauri/tauri.conf.json`、`Cargo.toml`、`package.json` 版本号保持一致。
- [ ] **versionCode 递增**：核对 `gen/android/tauri.properties` 中 `tauri.android.versionCode` 严格大于上一版本。
- [ ] **本地单元测试全绿**：`cargo test` 全量通过（包含播放队列状态机、四模式、断点持久化往返、SecretStore 统一凭据加解密）。
- [ ] **前端全量打包绿灯**：`npm run build`（`vue-tsc --noEmit && vite build`）零警告/零错误通过。
- [ ] **Release 签名通过**：使用发布密钥完成构建，`apksigner verify --verbose <apk_path>` 校验通过。
- [ ] **SHA256 校验和**：执行 `sha256sum Lumo-<version>-arm64.apk` 并记录在 Release Notes 中。

## 3. 权限与隐私规范（Privacy & Permissions）

- [ ] **声明权限最小化**：
  - `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE`：仅用于读取本地音乐文件
  - `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MEDIA_PLAYBACK`：仅用于系统媒体通知与后台保活
  - `POST_NOTIFICATIONS`：仅用于展示播放控制常驻通知
  - `INTERNET`：仅用于用户主动配置的 WebDAV 访问与手动点击的 GitHub Releases 更新检查
- [ ] **零私有遥测**：无任何第三方埋点统计、分析 SDK 或上报行为，全离线优先。
- [ ] **凭据安全脱敏**：日志与界面全程不打印或泄露 WebDAV 密码，密码采用 `SecretStore` 加密存储。
